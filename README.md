 ### 🧵 Objetivo
Facilitar o registro de vendas e precificação sem formulários complexos, usando linguagem natural via chat.

 ### 🧵 Funcionalidades-Chave
1. **Chat Principal**: Usuário registra vendas em linguagem natural (ex: "Vendi um tapete por 80 reais").  
   - O sistema interpreta, registra e sugere precificação futura.  
   - Botões rápidos: "Registrar venda", "Definir meta", "Ver relatório".  

2. **Classificação Automática de Produtos**:  
   - Identificação automática do tipo de produto de crochê (tapete, bolsa, amigurumi).  
   - Sugestão de categorias com opção de confirmação/ajuste.  

3. **Metas de Vendas**:  
   - Usuário define metas simples (ex: "Quero vender R$ 500 este mês").  
   - Barra de progresso mostra evolução.  
   - Alertas motivacionais.  

4. **Agente Financeiro Virtual**:  
   - Personagem que dá dicas rápidas de precificação e vendas.  
   - Exemplo: "Seu preço está abaixo da média, considere ajustar."  
   - Exemplo: "Você já vendeu 3 bolsas este mês, que tal criar um kit promocional?"  

5. **Relatórios Simples**:  
   - Total vendido no mês.  
   - Produtos mais vendidos.  
   - Margem sugerida de lucro.  
   - Gráficos básicos (pizza ou barras).  

6. **Resetar Vendas**:  
   - Comando simples via chat: "Resetar todas as vendas".  
   - O sistema apaga o histórico de vendas e reinicia os relatórios.  
   - Confirmação antes de executar: "Tem certeza que deseja apagar todas as vendas?"  
   - Útil para testes ou para começar um novo ciclo de vendas.  

### 🧵 Estilo e Tom
- Educativo, acessível e amigável.  
- Linguagem simples, sem jargões técnicos.  
- Experiência leve e motivadora para iniciantes.  

### 🧵  Validação Inicial
- Testar com grupo pequeno de crocheteiras iniciantes.  
- Observar clareza das mensagens e facilidade de uso.  
- Ajustar relatórios e recomendações conforme feedback.
